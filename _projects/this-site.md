## What it is

The site you're looking at right now — a static site built with Jekyll,
hosted free on GitHub Pages, with comments powered by giscus (backed by
GitHub Discussions, so no separate database or backend).

## How it's organized

- **Knowledge** entries live in `_knowledge/`, tagged with a `category`
- **Projects** entries live in `_projects/` (like this one)
- Both support comments, so anyone can push back or add context
